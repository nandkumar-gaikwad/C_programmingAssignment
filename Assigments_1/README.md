# Assignment 1 – C Programming

## About
This folder contains 5 C programming assignment programs to practice functions, loops, arithmetic operations, and basic problem-solving.

## Programs Included

### 1. Division of Two Numbers
- **Function:** `Divide()`
- **Description:** Divides two integers.
- **Input:** `15, 5`
- **Output:** `Division is 3`
- **Special Case:** Returns `-1` when the second number is zero.

### 2. Display Marvellous
- **Function:** `Display()`
- **Description:** Prints `Marvellous` 11 times using a `for` loop.
- **Output:** `Marvellous` printed 11 times.

### 3. Display Marvellous (Repeated Program)
- **Function:** `Display()`
- **Description:** Prints `Marvellous` 11 times using a `for` loop.

### 4. Display Marvellous (Repeated Program)
- **Function:** `Display()`
- **Description:** Prints `Marvellous` 11 times using a `for` loop.

### 5. Print Stars
- **Function:** `Accept()`
- **Description:** Prints the `*` character the specified number of times.
- **Input:** `5`
- **Output:** `*****`

- Return values
